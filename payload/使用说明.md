# 镜序 · Huimiao 本地视频工作台

这是通过 Huimiao 官方开放 API 工作的本地网页程序。界面和素材保存在自己电脑，生成视频需要联网及账户积分。

## 启动

- Windows 10/11 x64：双击 `启动工作台.cmd`。便携包自带 Node.js 运行时，无需 npm 安装。
- macOS / Linux：先从 https://nodejs.org/ 安装适配自己系统的 Node.js 24.5 或以上版本，在本目录运行 `node launcher.mjs`。也可以在终端运行 `sh start.sh`。
- 浏览器打开 http://127.0.0.1:4318 。只监听本机，不向局域网或公网开放。请保留启动窗口，关闭窗口会停止本地服务。
- 不能保证运行于所有历史系统：需要受支持的现代桌面系统、现代浏览器及相应 Node.js。Windows 随包运行时仅适用于 x64；其他架构请安装对应运行时。

## 第一次使用

1. 在 Huimiao 官网“API调用”准备完整 API Key（不是页面中的密钥前缀），权限包括读取模型、上传素材、查询下载、提交取消和余额。
2. 点击本地页面“接口设置”，填写密钥和所属站点。主站为 `https://huimiaovip.com`；分站填写分站根域名。密钥只在服务内存中保存，不写进项目文件，重启后重新填写。
3. **先选择默认模型**，再选分辨率、比例和时长。参数来自当前接口目录。改变模型后请确认其他参数。
4. 添加资产图或选择图片文件夹。支持 PNG、JPG、WebP；文件名使用角色、场景、物品的名称。图片可拖到资产库。
5. 粘贴分镜提示词，或导入 UTF-8 TXT / MD。每条标记独占一行：

```text
{分镜 1}
【分镜时长 5s】
林策坐在书桌前，拿起保温杯，镜头缓慢推进。

{分镜 2}
【分镜时长 10s】
林策放下保温杯，转头看向窗外。
```

也支持 `【分镜 1】`、Markdown 标题 `## 分镜 1`、每行一条或空行分隔。默认按每条正文的“总时长：30秒”等总时间读取；没有总时间时读取最后镜头的结束时间，例如 `｜镜头6｜23–30秒｜` 会使用 30 秒。小数秒向上取整（27.5 秒 → 28 秒），再按模型能力校验，不会默默缩短为模型上限。没有时间轴才使用时长标签，再没有则使用默认时长。可用“重新读取分镜时长”更新已有未提交任务，也可逐条手动修改。

6. 点击“解析分镜”，自动追加任务并按图片名称匹配。引用顺序按图片名称在正文首次出现的顺序。成对中文引号、直双引号和「」中的名称不参与自动匹配。请检查相似名字（例如 林策 / 林策妈妈），必要时手动移除误匹配。
7. 点击某条任务，再点击资产图增减引用；最终提示词会自动加上“名称是参考图N”对应关系。可修改每条的模型、时长、比例、分辨率。公共前后缀在最终提示词中合并。
8. 点击“批量生成”，检查任务数量和参考费用后确认。也可以单独生成。创建任务会消耗 Huimiao 积分。本版本不会自动撞审或自动新建失败重试任务。
9. 在“成片保存位置”点击“选择文件夹”，或填写已存在的绝对目录后点“保存目录”。单条和批量下载均保存到该合集选定的文件夹；未选择时，首次下载会弹出文件夹选择窗口。文件名包含分镜名称和任务编号，同名文件自动增加编号，避免覆盖。已下载的缓存也能另存到新目录。原始缓存仍在 `data/videos/`。

Windows 使用系统文件夹选择窗口，macOS 使用系统选择器，Linux 需要 zenity；没有选择器时可直接填写完整目录。取消选择不开始下载，目录失效时请重新选择。

## 恢复与暂停

- 解析后的每条分镜有“编辑分镜”按钮，可修改正文、模型、时长、画面比例、分辨率及引用素材；点击“保存修改”才保存，取消则丢弃此次编辑。绿色素材名称表示当前任务已经引用该图片，鼠标悬停或键盘聚焦可查看缩略图。编辑窗口下方提供实时引用预览和“按名称匹配”按钮。
- 已完成分镜也可编辑，修改作为待重新生成内容保存，原请求与成片保留。点击“重新生成”后必须在弹窗再次确认，才新建独立任务并计费；不修改正文也可重新生成。
- 同一次确认的重复网络请求复用同一重新生成任务；已有重新生成任务处于排队、生成或结果待确认状态时，阻止再次新建，避免重复计费。新视频独立显示，原视频可继续下载。

- 暂停只停止后续提交；正在上传、提交以及平台已接收的任务继续处理。点击批量生成可继续本地排队任务。
- 网络中断、创建结果不明确时显示“需恢复确认”。“恢复原请求”复用已保存的完整请求和幂等键，避免因网络重发重复计费。
- 服务重启不会自动创建新任务。填回原密钥和站点后，已知平台任务自动查询；未明确的提交通过“恢复原请求”恢复。
- 失败分镜可“复制”为新的草稿再修改生成。新副本会创建新任务，按平台规则计费。
- 平台排队任务可申请取消，是否成功以平台响应为准。

## 保存与换电脑

- `data/projects.json` 保存合集及任务；`data/assets/` 保存原图；`data/videos/` 保存下载成片。请备份整个 `data` 文件夹。不要在运行中手工修改它。
- “导出项目”生成带资产原图的 JSON，**不包含 API Key**。导入会建立新的草稿合集，清除原平台上传引用及计费请求。请检查后再生成。已经生成的视频请通过 `data/videos/` 单独复制。
- 若要连同任务编号及原幂等键继续处理，请在停止服务后复制整个程序与 `data`，使用原账户、原站点启动。不要在多台机器同时运行同一份队列副本。
- 本地图片直到提交对应任务时才会上传到 Huimiao 对象存储；复用同一素材时复用已验证对象键。切换密钥会清空素材上传引用。

### 内置订阅代理（无需 v2rayN）

Windows x64 便携版现在自带独立 sing-box 1.14.4 内核。把整个程序文件夹复制到另一台 Windows 10/11 x64 电脑后即可使用，不需要安装 v2rayN，不修改系统代理，也不需要管理员权限。

1. 在“成片保存位置”下方找到“内置订阅代理”。
2. 粘贴购买账户中的真实 HTTPS 订阅链接，点击“导入订阅 / 节点”。套餐网页 `/plan` 不是订阅内容。
3. 也可展开“粘贴节点内容或导入文件”，读取账户导出的 TXT、YAML、JSON 或直接粘贴节点链接。
4. 从节点列表选择线路，点击“连接所选节点”。软件自行启动随包的代理内核；下载方式自动切到“内置订阅代理”。
5. 点击“测试连接”，确认线路可用后下载视频到所选文件夹。连接失败时可更换节点，不会自动改用外部工具或直连。
6. 点击“断开”停止内核。关闭工作台服务也会关闭它拥有的内核；重启时会恢复上次选中的内置节点（选择了内置下载模式时）。

支持 SS、VMess、VLESS（含常见 TLS / Reality）、Trojan、Hysteria2、TUIC、AnyTLS 的常见配置，支持 Base64 URI 订阅、Clash YAML 和 sing-box JSON。特殊传输、插件、要求跳过证书校验的节点可能被跳过；页面显示导入数量和跳过数量。

订阅拉取直接访问订阅提供方，不经过订阅转换网站，也不依赖已有系统代理。若该订阅地址在当前网络无法直连读取，可以使用购买网站导出的订阅文件或粘贴节点内容导入。节点连接依然由程序自身完成。

此内置连接接管本工作台的视频预览和下载。订阅和节点信息保存在本机 `data/proxy-private.json`，其中含订阅令牌、节点密码，请不要公开分享此文件或整个 data 文件夹。普通项目导出不包含这些信息。换电脑可以重新导入订阅；搬迁私有 data 时请保管好访问权限。

源码版在 macOS / Linux 上需要把对应系统、架构的官方 sing-box 可执行文件放在 `runtime/sing-box/sing-box`，并赋予执行权限；Windows 包内核不能用于其他系统。Windows x64 便携包已全部附带。

在“成片保存位置”下方的“视频下载网络”设置：

- **跟随系统代理**：兼容选项，使用启动器读取的 Windows HTTP 代理或启动环境中的 HTTP_PROXY / HTTPS_PROXY。
- **内置订阅代理**：使用随包内核连接网页中选定的节点，不依赖外部客户端或系统代理。新安装默认选择此模式。
- **指定 HTTP / HTTPS 代理**：填写代理软件的 HTTP 或混合端口，例如 `http://127.0.0.1:10808`，点击“保存下载设置”。本机代理软件需要保持运行。支持无需账号密码的 HTTP / HTTPS 代理地址；SOCKS 专用端口不能直接使用。
- **直连下载**：视频连接不经过代理。

点击“测试连接”可检查到 Huimiao 公共首页的连通性和响应时间，不创建生成任务。测试成功不保证每个视频源都有同样速度。下载过程中显示已下载大小、总大小（视频源提供时）和平均速度。

此设置只影响视频预览和下载，不更改模型读取、素材上传或生成接口的代理。程序优先使用平台已返回的视频 HTTPS 直链，直链过期时通过官方内容接口重新获取；所有视频连接继续使用所选下载代理。指定代理失败会提示错误，不自动改成直连。

下载通过本地服务流式写入缓存，再保存到所选本地目录。已缓存的视频直接复制，不重复请求远程视频。软件内置的是代理接入能力，不自带免费的境外节点，也无法保证代理一定比直连更快；若平台只提供中转下载地址，代理也不能消除平台自身的中转瓶颈。

- 双击 `启动工作台.cmd` 后会等待本地服务启动成功，再打开系统默认浏览器。请先把整个 ZIP 解压到文件夹中运行。启动失败会保留错误窗口，并把诊断写入同目录的 `startup.log`。
- 服务已启动而浏览器没有打开时，手动访问 `http://127.0.0.1:4318`。再次运行启动器会复用已有服务，不会重复提交任务。

- Windows 启动器会读取已开启的系统 HTTP 代理。其他系统可在启动前设置 `HTTPS_PROXY` / `HTTP_PROXY`；支持 Node.js 的环境代理。PAC 和 SOCKS 专用代理不自动转换，需使用可用的 HTTP 代理端口。
- “连接失败”：检查密钥是否完整、是否过期、所属站点是否正确、网络/代理是否可用。
- “模型参数无效”：刷新接口设置读取最新目录，并检查图片数量、条件限制、时长、比例与分辨率。基础能力在本地校验，复杂条件由官方服务端最终校验。
- 报价根据模型目录中准确匹配的分辨率与时长价格行计算。Token 计费和其他复杂计费不做总价承诺，最终以平台实际结算为准。余额显示为连接时的快照，重新连接可刷新。
- `4318` 被占用时，启动前设置环境变量 `PORT` 为其他端口。

## 开发与验证

程序运行无需 npm 安装依赖，随包包含 YAML 解析库和独立 sing-box 代理内核。`npm test` 运行解析、参数、队列、内置代理及下载测试；`npm start` 启动服务。第三方许可及内核源码见 `THIRD-PARTY.md` 和 `runtime/sing-box/`。

官方文档：https://huimiaovip.com/docs/api-guide.md 。实现于 2026-11-18 对照官网文档。本版本针对资产图工作流，暂不提供音频/视频参考素材上传、剪辑合成或官方网页全部模型特殊参数。需要付费 API Key 才能完成真实生成；交付测试使用模拟接口，不消耗账户积分。

### 资产删除、成片预览与节点检测（1.2）

- 每张合集图片右上角的 × 可删除图片；确认后解除分镜素材引用，不影响已生成的视频。正在排队、上传或生成中的引用图需等任务结束。点击“恢复上次删除”可取回图片，再重新匹配引用。图片文件暂留本机供恢复，普通项目导出不包含已删除图片。
- 已完成分镜点击“▶ 预览成片”，即可播放、拖动进度、调音量和全屏查看；通过当前下载网络转发视频，不写入成片保存目录。关闭播放器会停止读取；满意后点击下载，按自选目录保存。已缓存的视频优先从缓存播放。
- 内置订阅代理支持检测所选节点、检测全部节点、停止检测。检测使用独立内核，通过节点实际访问 Huimiao，不中断正在连接的节点。显示连通、响应毫秒数和 HTTP 状态；失败表示此目标在本次检测中不可达，响应耗时不代表视频下载速度。
- 按此版本使用者要求，分发包包含 distribution-subscription.json 中的订阅地址，首次启动自动读取并导入。持有整个包的人能够读取、使用这份订阅。普通项目 JSON 导出不包含订阅。若发给其他人且不想共享订阅，请先移除该文件。

### 1.3 生成历史与保留记录升级

同一分镜的重新生成集中显示为一个分镜卡片，卡片默认预览或下载最新已完成的视频。“生成记录”可查看每一版的状态、平台编号、参数和提交内容，并逐版预览或下载。新版本仍在生成时，默认预览最近已完成版。既有任务自动按父任务关系整理，不重新提交、不清除旧成片。早期记录没有提交时间时明确标记。

**已有软件升级**：将“镜序-Huimiao-仅更新软件.zip”解压到单独文件夹；先关闭原来的启动窗口，运行更新包中的“更新软件.cmd”，选择原软件文件夹。它校验文件并备份旧程序到 .updates，只替换程序，不覆盖 data，不带其他电脑的记录。完成后从原文件夹启动软件并刷新浏览器。每台电脑分别运行这一步，继续使用各自的记录。请勿删除旧文件夹后再解压全新安装包来升级。

**记录迁移/备份**：关闭工作台，运行原软件文件夹里的“备份本机记录.cmd”，选择保存位置。工具会提取整个 data（合集、素材、所有生成版本、已缓存视频、节点设置），生成单独的“镜序记录-…”文件夹。复制此记录备份到另一台电脑，运行那台电脑软件里的“恢复本机记录.cmd”，选择该记录备份文件夹。恢复前会自动备份目标电脑当前记录；恢复是切换到备份中的记录集合，不合并不同电脑项目。API Key 仍需重新输入，未缓存且平台已过期的视频无法凭本地记录保证再次获取。

记录备份包含订阅和节点凭据，请按私人资料保管。单个项目的“导出项目”依旧用于创建新草稿，迁移全部历史请使用完整记录备份工具。也可在关闭软件后直接复制整个 data 到新软件目录。

### 1.3.1 轻量增量包
以后默认只发布“仅更新软件.zip”，只包含相对 1.2 基线有变化的文件和小型更新工具；不重复包含 Node.js、sing-box、内核源码或未变动的 YAML 库。兼容已有 1.2 / 1.3 系列的完整便携安装。更新时选择原软件目录，由原目录自带的 Node.js 执行更新，无需另外安装 Node.js。更新前校验原有运行组件，缺失或不匹配时停止；相同文件直接跳过，不重复备份。完整安装包仅首次安装或运行组件升级时另行提供。data 中的记录照常保留。

### 1.4 GitHub 在线更新
安装本地 1.4 更新包一次后，打开左侧“软件更新”→“检查更新”→“立即更新”。程序直接读取公开仓库 676216294-beep/jingxu-updates 的最新正式 Release，下载对应增量包与 SHA256SUMS.txt，验证包和文件清单后自动重启。各电脑保留自己的 data。更新失败会显示原因并保留程序备份；网络受限时可先连接内置节点再检查更新。生成、下载、预览和节点检测进行中时暂不安装。API Key 通过本机子进程内存传递，不写入更新包或日志。

1.4.1：GitHub API 返回限流或网络错误时，自动读取公开最新 Release 页面识别版本；仍对下载包进行 SHA-256 和逐文件校验。

### 1.4.2 发布方式调整
软件的在线更新入口和使用方式保持不变。发布端现在由插件提交程序文件与更新清单，GitHub Actions 自动校验、打包、发布正式版本，不再手工通过网页上传附件。本版仅用于验证新发布流程。

### 1.4.3 Windows 本地更新入口修复
修复 Windows PowerShell 5.1 误读无 BOM 中文脚本导致的语法错误。更新入口仅用 ASCII 代码，中文界面文字在运行时按 UTF-8 解码；其他含中文 PowerShell 文件保留 UTF-8 BOM。已验证中文、空格和括号路径。旧版更新包遇到 update-bootstrap.ps1 语法错误时，先关闭报错窗口，将入口修复补丁中的 update-bootstrap.ps1 覆盖到原更新包解压文件夹，再运行“更新软件.cmd”；不要把补丁放进 data 目录。

### 1.4.4 失败后重新生成
请求失败、生成失败或取消后可点击“重新生成”，弹窗确认后新建一次生成，原失败记录保留在生成历史中；失败任务也支持编辑再生成。若上次提交结果未知，则该按钮先按原请求标识重试确认结果，不直接创建可能重复计费的新任务。同一分镜有任务正在进行时阻止重复提交。
